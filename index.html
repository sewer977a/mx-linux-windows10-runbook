MX Linux 23.6 to Windows 10 Transformation Runbook

Step-by-step guide for configuring Xfce on MX Linux 23.6 with Windows 10 themes, Segoe UI fonts, cursors, and LightDM login settings.

Phase 1: Move the taskbar to the bottom

MX Linux places the panel vertically along the left side of the screen by default. You can move it to the bottom edge in MX Tweak:

  1. Press the Super (Windows) key, type MX Tweak, and press Enter.
  2. Select the Panel tab.
  3. Check Display panel horizontally and choose Bottom from the position menu.
  4. Click Apply in the bottom-right corner.
Check: The panel now runs horizontally along the bottom of the screen with the Start button on the left.

Phase 2: Download Windows 10 themes and icons

The B00merang Project publishes GTK themes and icon packs that style Xfce windows and folders like Windows 10.

  1. Open Xfce Terminal and install git if you do not have it yet (sudo asks for your administrator password): 
    sudo apt update && sudo apt install -y git
  2. Create the local theme and icon directories inside your home folder: 
    mkdir -p ~/.themes ~/.icons
  3. Clone the Light and Dark GTK themes along with the icon pack: 
    git clone https://github.com/B00merang-Project/Windows-10.git ~/.themes/Windows-10
git clone https://github.com/B00merang-Project/Windows-10-Dark.git ~/.themes/Windows-10-Dark
git clone https://github.com/B00merang-Artwork/Windows-10.git ~/.icons/Windows-10-Icons
Check: Run ls ~/.themes ~/.icons in the terminal and confirm that Windows-10, Windows-10-Dark, and Windows-10-Icons are listed.

Phase 3: Apply the theme, window borders, and icons

Xfce uses separate settings for inside-window controls (GTK) and top titlebar borders (xfwm4), so you need to update both panels.

  1. Open the Start menu, go to Settings, and select Appearance. On the Style tab, choose Windows-10 for light mode or Windows-10-Dark for dark mode. Then switch to the Icons tab and select Windows-10-Icons.
  2. Return to the Settings Manager and open Window Manager. On the Style tab, select Windows-10 or Windows-10-Dark to match your choice above. Under Button layout, make sure Menu is on the left and Minimize, Maximize, and Close are on the right.
Check: Open the Thunar file manager. The window now uses square Windows 10 titlebar buttons with a red close button when you hover over it, and folders use flat yellow icons.

Phase 4: Start menu and taskbar layout

  1. To replace the Start button icon, right-click the menu button at the bottom-left of the panel and choose Properties. On the Appearance tab, click the Icon button, change the filter to Image Files or All Icons, and pick the Windows logo from ~/.icons/Windows-10-Icons/. Set Display to Icon so the word "Menu" is hidden.
  2. To group and pin taskbar icons, right-click an empty spot on the panel, open Panel, select Panel Preferences, and switch to the Items tab:
    • If Docklike Taskbar is in the list (pre-installed on MX Linux 23.6), open apps already group into square icons. You can right-click any running app icon and choose Pin to Dock.
    • If your panel uses Window Buttons instead, select it, click the gear icon to edit it, uncheck Show button labels, and set Window grouping to Always.
  3. To match the Windows 10 bar height and color, stay in Panel Preferences. On the Display tab, set Row Size (pixels) to 40. On the Appearance tab, set Background Style to Solid color and pick dark charcoal (#101010).
Check: Open applications appear as square icons along the bottom bar with active indicators underneath.

Phase 5: Wallpaper and desktop icons

  1. Right-click an empty area of the desktop and select Desktop Settings.
  2. On the Background tab, use the Folder menu to choose the directory where you saved your Windows 10 wallpaper.
  3. Switch to the Icons tab, set Icon size to 48, and under Default Icons check Home, Filesystem, and Trash. Uncheck Removable Devices if you do not want mounted drives cluttering the desktop.

Phase 6: Install Windows 10 fonts (Segoe UI and Microsoft Core Fonts)

Windows 10 uses Segoe UI for interface labels and titlebars, along with standard Microsoft fonts such as Arial and Times New Roman for documents and web pages.

  1. Install the Microsoft core fonts package and fontconfig from the Debian and MX repositories: 
    sudo apt update && sudo apt install -y ttf-mscorefonts-installer fontconfig

    When the blue license prompt appears in the terminal, press Tab to highlight OK and press Enter, then select Yes to accept the license agreement.

  2. Clone and run the Segoe UI font installer: 
    git clone https://github.com/mrbvrz/segoe-ui-linux.git /tmp/segoe-ui-linux
cd /tmp/segoe-ui-linux
chmod +x install.sh
./install.sh
  3. Check that fontconfig detects Segoe UI: 
    fc-list | grep -i "Segoe UI"
  4. Apply Segoe UI in Xfce:
    • Open the Start menu, go to Settings, select Appearance, and open the Fonts tab.
    • Set Default Font to Segoe UI Regular, size 9 or 10.
    • Check Enable anti-aliasing, set Hinting to Slight, and set Sub-pixel order to RGB.
    • Open Settings, select Window Manager, and on the Style tab set Title font to Segoe UI Semibold (or Regular), size 9.
Check: Open Thunar. Both the window titlebar and the folder list now use Segoe UI.

Phase 7: Install and lock Windows 10 cursors

The Win10OS-cursors package provides the white Windows 10 pointer and the blue spinning ring animation.

  1. Clone the cursor repository and copy the built theme into ~/.icons: 
    git clone https://github.com/yeyushengfan258/Win10OS-cursors.git /tmp/Win10OS-cursors
mkdir -p ~/.icons
cp -r /tmp/Win10OS-cursors/dist ~/.icons/Win10OS-cursors
  2. Open the Start menu, go to Settings, select Mouse and Touchpad, and switch to the Theme tab. Choose Win10OS-cursors and set Cursor Size to 24.
  3. Write a default cursor fallback file and update xsettings so the cursor does not switch back to the Xfce default over the desktop or inside non-GTK windows: 
    mkdir -p ~/.icons/default
printf "[Icon Theme]
Inherits=Win10OS-cursors
" > ~/.icons/default/index.theme
xfconf-query --channel xsettings --property /Gtk/CursorThemeName --set "Win10OS-cursors"
Check: Log out of Xfce and log back in. Move the pointer across the desktop, panel, and browser window to confirm the Windows 10 arrow stays active everywhere.

Phase 8: Save your panel and session

Saving a panel backup and a clean session state keeps your layout intact when you reboot.

  1. Open the Start menu, go to Settings, and open Panel Profiles. Click Save at the bottom, name the profile Windows-10-Permanent, and confirm.
  2. Close all open windows on your desktop, then open the Start menu, go to Settings, and select Session and Startup. On the General tab, make sure Automatically save session on logout is unchecked. Switch to the Current Session tab and click Save Session.
Check: Reboot with sudo reboot and confirm that the bottom panel, theme, fonts, and cursor load on login.

Phase 9 (optional): Windows 10 login screen (LightDM)

The LightDM login screen runs as root before your user folder is mounted, so it cannot read themes inside ~/.themes or ~/.icons. Copy the files into /usr/share first:

  1. Copy the dark theme and icon pack into the system directories: 
    sudo cp -r ~/.themes/Windows-10-Dark /usr/share/themes/
sudo cp -r ~/.icons/Windows-10-Icons /usr/share/icons/
  2. Open MX Tweak, switch to the LightDM (or Login) tab, and enter your administrator password. Set Theme to Windows-10-Dark, set Icons to Windows-10-Icons, pick a background image stored under /usr/share/backgrounds/, and click Apply.

Phase 10: Troubleshooting

  • If the cursor reverts inside Flatpak apps, run flatpak override --user --filesystem=~/.icons:ro in the terminal so sandboxed apps can read your local ~/.icons folder.
  • If fonts look thin on a 1080p monitor, open Settings, select Appearance, go to the Fonts tab, enable Custom DPI setting at 96, and test Slight versus Medium hinting to see which matches your panel best.
  • If the taskbar layout gets changed by accident, open Panel Profiles, select Windows-10-Permanent, and click Apply.
