Phase 1: Move the Taskbar to the Bottom

MX Linux places the taskbar vertically on the left edge of the screen by default. Move it to the bottom using MX Tweak:

  1. Press the Super (Windows) key, type MX Tweak, and press Enter.
  2. Open the Panel tab.
  3. Check Display panel horizontally and select Bottom from the position drop-down menu.
  4. Click Apply in the bottom-right corner.
Verification: The taskbar snaps horizontally across the bottom edge of your screen with the Start button on the far left.

Phase 2: Download Windows 10 Themes and Icons

The B00merang Project maintains open-source Windows 10 GTK themes and icon packs that replicate Windows 10 File Explorer, buttons, and window titlebars.

  1. Open Xfce Terminal and install git if it is not already installed: 
    sudo apt update && sudo apt install -y git
  2. Create the local theme and icon folders in your home directory: 
    mkdir -p ~/.themes ~/.icons
  3. Download both the Light and Dark Windows 10 GTK themes and the Windows 10 icon pack: 
    git clone https://github.com/B00merang-Project/Windows-10.git ~/.themes/Windows-10
git clone https://github.com/B00merang-Project/Windows-10-Dark.git ~/.themes/Windows-10-Dark
git clone https://github.com/B00merang-Artwork/Windows-10.git ~/.icons/Windows-10-Icons
Verification: Run ls ~/.themes ~/.icons in the terminal and confirm that Windows-10, Windows-10-Dark, and Windows-10-Icons appear in the output.

Phase 3: Apply the Theme, Window Borders, and Icons

Xfce separates internal application styling from the top window titlebars (Minimize, Maximize, and Close buttons), so you need to set both.

  1. Set Application Style and Icons:
    • Open the Start Menu → Settings → Appearance.
    • Under the Style tab, select Windows-10 (for Light mode) or Windows-10-Dark (for Dark mode).
    • Switch to the Icons tab and select Windows-10-Icons.
  2. Set Window Titlebars:
    • Return to Settings Manager and open Window Manager.
    • Under the Style tab, select Windows-10 or Windows-10-Dark from the theme list.
    • Under Button layout, verify that Menu is on the left and Minimize, Maximize, Close are on the right.
Verification: Open the Thunar File Manager—the window now displays square Windows 10 titlebar buttons (with a red close button on hover) and flat yellow Windows 10 folders.

Phase 4: Customize the Start Menu and Taskbar Layout

  1. Change the Start Button Icon:
    • Right-click the Start Menu button on the bottom-left of the panel and select Properties.
    • In the Appearance tab, click the Icon button, switch the dropdown to Image Files or All Icons, and select the Windows logo from ~/.icons/Windows-10-Icons/.
    • Set Display to Icon (so the word "Menu" is hidden, leaving only the logo).
  2. Enable Pinned Taskbar Icons (Windows 10 Superbar behavior):
    • Right-click an empty space on the taskbar and select Panel → Panel Preferences → Items tab.
    • If using Docklike Taskbar (pre-installed on MX Linux 23.6), open apps automatically group into square icons that you can right-click and Pin to Dock just like Windows 10.
    • If using Window Buttons, select it, click the Edit (gear) icon, uncheck Show button labels, and set Window grouping to Always.
  3. Match Taskbar Color & Size:
    • In Panel Preferences → Display tab, set Row Size (pixels) to 40.
    • In the Appearance tab, switch Background Style to Solid color and pick dark charcoal (#101010).
Verification: Launched applications appear as square icons along the bottom bar with active indicators underneath.

Phase 5: Set Wallpaper and Desktop Icons

  1. Right-click anywhere on your desktop and select Desktop Settings.
  2. In the Background tab, click the Folder dropdown to select the folder containing your Windows 10 wallpaper.
  3. Switch to the Icons tab:
    • Set Icon size to 48.
    • Under Default Icons, check Home (User folder), Filesystem (This PC), and Trash (Recycle Bin), and uncheck Removable Devices for a clean desktop.

Phase 6: Install Windows 10 Fonts (Segoe UI & Microsoft Core Fonts)

Windows 10 relies on Segoe UI for system menus, titlebars, and file explorer labels, alongside classic Microsoft fonts for applications and web pages.

  1. Install Microsoft Core Fonts from Debian/MX Repositories: 
    sudo apt update && sudo apt install -y ttf-mscorefonts-installer fontconfig

    Tip: When the blue package configuration screen appears in the terminal, press Tab to highlight OK and press Enter, then select Yes to accept the EULA.

  2. Install the Segoe UI Font Family: 
    git clone https://github.com/mrbvrz/segoe-ui-linux.git /tmp/segoe-ui-linux
cd /tmp/segoe-ui-linux
chmod +x install.sh
./install.sh
  3. Verify Segoe UI Recognition: 
    fc-list | grep -i "Segoe UI"
  4. Set Segoe UI Permanently Across Xfce:
    • Open Start Menu → Settings → Appearance → Fonts tab.
    • Change Default Font to Segoe UI Regular, size 9 or 10.
    • Check Enable anti-aliasing, set Hinting to Slight, and set Sub-pixel order to RGB (matches Windows ClearType).
    • Open Settings → Window Manager → Style tab, click the Title font button, and set it to Segoe UI Semibold (or Regular), size 9.
Verification: Open Thunar File Manager; both the top window title and the sidebar folder names immediately render in crisp Segoe UI text.

Phase 7: Install and Lock the Windows 10 Mouse Cursor

The dedicated Win10OS-cursors package adds the complete Windows 10 cursor set, including the blue spinning background ring and busy animations.

  1. Download and Install Win10OS Cursors: 
    git clone https://github.com/yeyushengfan258/Win10OS-cursors.git /tmp/Win10OS-cursors
mkdir -p ~/.icons
cp -r /tmp/Win10OS-cursors/dist ~/.icons/Win10OS-cursors
  2. Activate the Cursor in Xfce Settings:
    • Open Start Menu → Settings → Mouse and Touchpad → Theme tab.
    • Select Win10OS-cursors and set Cursor Size to 24.
  3. Make the Cursor Permanent Across All Apps (Prevent Revert Glitch): 
    mkdir -p ~/.icons/default
printf "[Icon Theme]
Inherits=Win10OS-cursors
" > ~/.icons/default/index.theme
xfconf-query --channel xsettings --property /Gtk/CursorThemeName --set "Win10OS-cursors"
Verification: Log out of your Xfce session and log back in. Move your mouse over the desktop, taskbar, and browser window—the white Windows 10 arrow and blue loading ring remain consistent everywhere.

Phase 8: Lock In Your Permanent Setup

Backing up your panel profile and saving a clean Xfce session guarantees nothing resets across reboots or updates.

  1. Save a Permanent Panel Backup (Panel Profiles):
    • Open Start Menu → Settings → Panel Profiles.
    • Click Save at the bottom, name the profile Windows-10-Permanent, and click Save.
  2. Lock Your Xfce Session State:
    • Close all open applications on your desktop.
    • Open Start Menu → Settings → Session and Startup.
    • Under the General tab, ensure Automatically save session on logout is unchecked.
    • Switch to the Current Session tab and click Save Session.
Verification: Reboot your computer (sudo reboot). Your bottom taskbar, Windows 10 theme, Segoe UI fonts, and Windows 10 cursor load immediately upon login.

Phase 9 (Optional): Windows 10 Login Screen (LightDM)

Because the login screen runs as root before your personal profile loads, copy the theme and icons to the system directory so LightDM can use them:

  1. Copy the Theme and Icons System-Wide: 
    sudo cp -r ~/.themes/Windows-10-Dark /usr/share/themes/
sudo cp -r ~/.icons/Windows-10-Icons /usr/share/icons/
  2. Configure LightDM via MX Tweak:
    • Open MX Tweak → click the LightDM (or Login) tab, and enter your password.
    • Change Theme to Windows-10-Dark and Icons to Windows-10-Icons.
    • Set the Background to an image stored in /usr/share/backgrounds/.
    • Click Apply.

Phase 10: Quick Troubleshooting Reference

  • Cursor reverts inside Flatpak apps: Run flatpak override --user --filesystem=~/.icons:ro in the terminal so sandboxed apps can read your Windows 10 cursor theme.
  • Fonts look thin on 1080p monitors: In Settings → Appearance → Fonts, set Custom DPI setting to 96 and change Hinting between Slight and Medium to match your monitor's sub-pixel layout.
  • Restore Panel if accidentally modified: Open Panel Profiles, select Windows-10-Permanent, and click Apply.
